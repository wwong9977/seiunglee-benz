# 상담 접수 연결 방법 (구글 시트 · 무료)

홈페이지는 GitHub Pages(정적 호스팅)라서 서버가 없습니다. 상담 폼에 입력된 내용을 저장하려면 별도의 접수 서비스가 필요합니다.
이 폴더의 `Code.gs`를 과장님 구글 계정의 **Google Apps Script**로 올려 쓰면, 비용 없이 접수 내용이 **과장님 구글 시트**에 쌓입니다.

- 비용: 무료 (Google 계정 기본 한도 안에서 운영)
- 개인정보 위치: 과장님 구글 드라이브의 시트에만 저장됩니다. 공개 저장소(GitHub)와 홈페이지 코드에는 고객 정보가 남지 않습니다.
- 비밀키: 필요 없습니다. 홈페이지에는 웹앱 주소(…/exec)만 들어갑니다.

## 1. 시트 만들기 (3분)
1. [sheets.new](https://sheets.new) 를 열어 새 스프레드시트를 만들고 이름을 `벤츠 상담 접수`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 열린 편집기의 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(💾)합니다.

## 2. 처음 한 번 실행 (1분)
1. 편집기 위쪽 함수 선택 칸에서 `setup` 을 고르고 **실행** 을 누릅니다.
2. "권한 검토" 창이 뜨면 과장님 계정을 선택하고 **허용** 합니다.
   ("확인되지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동** 을 누르면 됩니다. 과장님 본인이 만든 스크립트라서 나오는 안내입니다.)
3. 시트에 `상담접수` 탭과 머리글이 생겼는지 확인합니다.

## 3. 웹앱으로 배포 (2분)
1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 유형 선택(⚙️)에서 **웹 앱** 을 고릅니다.
3. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** 를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 홈페이지에 연결
복사한 주소를 Claude에게 전달하면 `assets/data.js`의 `formEndpoint`에 넣고 접수 테스트를 진행합니다.
(직접 하실 경우: `formEndpoint: "",` 의 따옴표 안에 주소를 붙여 넣습니다.)

## 5. 새 접수 알림 메일 (선택)
`Code.gs` 맨 위 `NOTIFY_EMAIL = ''` 따옴표 안에 메일 주소를 넣고 저장한 뒤,
**배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 누르면 접수 때마다 메일이 옵니다.
※ 실제 알림이 발송되므로 연결 테스트가 끝난 뒤 켜는 것을 권장합니다.

## 동작 요약
| 상황 | 홈페이지 표시 | 시트 |
|---|---|---|
| 정상 저장 | "상담 신청이 접수되었습니다 (접수번호)" | 새 행 추가 |
| 같은 신청을 다시 보냄(재시도·두 번 클릭) | 접수 완료 (같은 접수번호) | 추가 안 됨 |
| 같은 연락처+모델 10분 내 재신청 | 접수 완료 | 추가 안 됨 |
| 입력 오류 / 서버 오류 / 응답 없음 | "접수가 완료되지 않았습니다" + 다시 시도 + 전화·카카오 안내 | 추가 안 됨 |

## 수정·되돌리기
- 스크립트를 고친 뒤에는 **배포 관리 → 새 버전** 으로 다시 배포해야 반영됩니다(주소는 그대로).
- 접수를 잠시 멈추려면 data.js의 `formEndpoint`를 `""`로 비우면 됩니다. 홈페이지는 전화·카카오 안내로 바뀝니다.
- 개인정보 보유기간은 수집일로부터 1개월입니다. `setup` 실행 시 매일 새벽 4시에 1개월이 지난 행을 자동 삭제하도록 예약됩니다(`RETENTION_DAYS`). 상담 중인 고객 정보를 더 보관해야 하면 별도 고객 관리 파일로 옮겨 두세요.
